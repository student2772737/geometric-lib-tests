# План тестирования библиотеки геометрических вычислений

## 1. Цели и задачи тестирования

Цель тестирования — проверить правильность работы функций библиотеки `geometric lib`, которые вычисляют площадь и периметр геометрических фигур.

Задачи тестирования:
- подобрать входные значения для проверки функций;
- рассчитать ожидаемые результаты для выбранных значений;
- написать unit-тесты с использованием модуля `unittest`;
- запустить тесты и сравнить результаты работы функций с ожидаемыми значениями.

---

## 2. Описание тестируемого продукта

Geometric lib — библиотека, написанная на языке Python. Она предназначена для вычисления площади и периметра круга, прямоугольника, квадрата и треугольника. Функции получают размеры фигуры и возвращают вычисленное значение площади или периметра.

---

## 3. Область тестирования

В ходе тестирования проверяются четыре модуля библиотеки: `rectangle`, `square`, `triangle` и `circle`. В каждом модуле тестируются две функции: `area` для вычисления площади и `perimeter` для вычисления периметра фигуры. Для круга функция `perimeter` вычисляет длину окружности.

Проверяются вычисления функций. Проверка корректности размеров и существования треугольника не входит в область тестирования: исходные функции её не выполняют.

---

## 4. Стратегия тестирования

Для проверки отдельных функций используется модульное тестирование с помощью `unittest`. Для каждой функции подобраны целые, дробные, нулевые и положительные значения, близкие к нулю.

Ожидаемые результаты рассчитываются по формулам площади и периметра. Затем они сравниваются с результатами функций: для точного сравнения используется `assertEqual`, а для дробных результатов — `assertAlmostEqual`, который учитывает небольшую погрешность вычислений.

---

## 5. Критерии приёмки

Тестирование считается успешно завершённым, если все 37 тестов выполняются без ошибок и неуспешных проверок. Результаты функций должны совпадать с ожидаемыми значениями для выбранных входных данных; для дробных результатов допускается небольшая погрешность сравнения. По итогам запуска `unittest` должен вывести статус `OK`.

Успешное прохождение подтверждает работу функций на проверенных данных, но не доказывает отсутствие ошибок для всех возможных значений.

---

## 6. Ожидаемые результаты

По итогам тестирования ожидается получить результаты запуска unit-тестов: количество выполненных тестов и их общий статус. Если все проверки пройдут успешно, `unittest` выведет `OK`.

Если тест не пройдёт, необходимо зафиксировать название теста и проверяемой функции, входные данные, ожидаемый и фактический результаты. Эти сведения помогут разобраться в причине ошибки.

---

## Запуск тестов

Unit-тесты находятся в файлах:

- `test_circle.py`
- `test_rectangle.py`
- `test_square.py`
- `test_triangle.py`

Для запуска всех тестов нужно открыть терминал в корневой папке проекта и выполнить:

```powershell
py -m unittest discover -v
```

При успешном выполнении всех тестов в конце вывода появится `OK`.
